# slovo · 乌克兰语词汇闪卡

一个中文界面的乌克兰语词汇闪卡网页。专注记单词，无需注册、后端服务或 API 密钥。

- 48 个 A1 入门词汇，涵盖问候、生活、饮食、旅行、自然和数字颜色。
- 翻卡查看中文、词性、乌克兰语例句和翻译。
- 分类筛选、中乌文搜索、随机顺序、收藏与待复习列表。
- 标记「还需练习」或「我记住了」，查看掌握度及每日 10 词目标。
- 收藏和学习记录保存在当前浏览器的 localStorage。
- 响应式布局；支持键盘操作和减少动画偏好。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（已使用 Node.js 24 验证）。

```bash
npm ci
npm run dev -- --port 5173
```

## 构建

```bash
npm run build
npm run preview -- --port 4173
```

构建产物位于 `dist/`，可以部署到静态网站托管服务。字体随站点构建，无需访问第三方字体服务。

## 发布到手机可直接访问的网站

仓库已包含 `.github/workflows/pages.yml`，推送到 `main` 后自动构建并部署到 GitHub Pages。

首次使用时，在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。如果首次运行发生在启用 Pages 之前，在 **Actions → Deploy flashcards to GitHub Pages** 中重新运行工作流即可。

发布成功后，可从工作流的 `github-pages` 部署结果获取实际网址，在手机浏览器直接打开。开启云开发环境本身不会将网站发布到公网。

## 使用

先回想单词的意思，点击卡片中间区域翻面，再选择记忆情况。

| 快捷键 | 操作 |
| --- | --- |
| 空格 | 翻面 |
| 左 / 右方向键 | 上一张 / 下一张 |
| 1 / 2 | 还需练习 / 我记住了（翻面后） |
| P | 朗读当前单词 |

发音使用浏览器的 Web Speech API，仅在设备提供乌克兰语语音时播放。没有语音包时显示提示，不会用其他语言冒充乌克兰语发音。词卡的拉丁字母转写是学习辅助，不是国际音标；尖音符表示重读音节。

数据不上传服务器，不会在不同设备之间同步；清除网站数据会删除学习进度。修改词库可编辑 `src/words.ts`，每个单词的 `id` 应保持唯一且稳定。
