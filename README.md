# slovo · 乌克兰语词汇闪卡

一个中文界面的乌克兰语词汇闪卡网页。专注记单词，无需注册、后端服务或 API 密钥。

- 默认学习 128 张新词卡：A2 日常应用 32 张、B1 交流表达 32 张、储能系统 32 张、能源行业 32 张。
- 日常词覆盖生活交流、工作职场、旅行事务和社会表达；可以按难度与主题组合筛选。
- 行业词含 BESS、SOC、SOH、DOD、BMS、EMS、PCS、LFP、RTE、C-rate，以及并网、调度、削峰、负荷转移等表达。
- 保留原有 48 张 A1 词卡及其稳定 ID；在「A1 · 基础复习」中学习，已有收藏和进度不会因词库升级而删除。共 176 张词卡。
- 翻卡查看中文、词性、乌克兰语例句和翻译。
- 分类与难度筛选、中乌文及行业缩写搜索、随机顺序、收藏与待复习列表。
- 标记「还需练习」或「我记住了」，查看掌握度及每日 10 词目标。
- 收藏和学习记录保存在当前浏览器的 localStorage。
- 开启「自动朗读」后，切换词卡自动播放乌克兰语，切词时停止上一条，仍可手动重播；开关偏好保存在本机。
- 响应式布局；支持键盘操作和减少动画偏好。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（已使用 Node.js 24 验证）。

```bash
npm ci
npm run dev -- --port 5173
```

## 构建

```bash
npm run build
npm run preview -- --port 4173
```

构建产物位于 `dist/`，可以部署到静态网站托管服务。字体随站点构建，无需访问第三方字体服务。

## 发布到手机可直接访问的网站

仓库已包含 `.github/workflows/pages.yml`，推送到 `main` 后自动构建并部署到 GitHub Pages。

首次使用时，在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。如果首次运行发生在启用 Pages 之前，在 **Actions → Deploy flashcards to GitHub Pages** 中重新运行工作流即可。

发布成功后，可从工作流的 `github-pages` 部署结果获取实际网址，在手机浏览器直接打开。开启云开发环境本身不会将网站发布到公网。

## 使用

先回想单词的意思，点击卡片中间区域翻面，再选择记忆情况。

| 快捷键 | 操作 |
| --- | --- |
| 空格 | 翻面 |
| 左 / 右方向键 | 上一张 / 下一张 |
| 1 / 2 | 还需练习 / 我记住了（翻面后） |
| P | 朗读当前单词 |

发音使用浏览器的 Web Speech API，仅在设备提供乌克兰语语音时播放。没有语音包时显示提示，不会用其他语言冒充乌克兰语发音。词卡的拉丁字母转写是学习辅助，不是国际音标；尖音符表示重读音节。

「自动朗读」会在开启时朗读当前词卡，之后跟随切词播放；翻面查看释义不会重复播放。由于手机浏览器的自动播放限制，刷新后会保留开关，但需要点击「点此开启声音」或喇叭后才恢复自动播放。加载语音列表时会等待系统的 `voiceschanged` 通知；无乌克兰语语音或播放被阻止时暂停自动播放并提示重试，避免每张卡重复报错。进入帮助、学习完成或离开页面时会停止当前声音。

数据不上传服务器，不会在不同设备之间同步；清除网站数据会删除学习进度。修改词库可编辑 `src/words.ts`，每个单词的 `id` 应保持唯一且稳定。

## 词库与难度

`src/generalWords.ts` 提供 A2–B1 日常词汇；`src/industryWords.ts` 提供储能和能源行业词汇；`src/words.ts` 保留 A1 基础词并汇总词库。专业卡显示常用缩写，并为功率与能量容量、SOC 与 SOH、往返效率等易混概念补充说明。

A2–B1 是面向学习者的教学分组，不是官方逐词 CEFR 认证；行业术语独立标记为「行业」，不强行归入 A2 或 B1。进入收藏或待复习列表时，默认展示全部难度，便于找到原有 A1 记录。
